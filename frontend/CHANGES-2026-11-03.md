# Changes - 2026-11-03 (Jarvis)

## Alerts page: Duplicates toggle
- New "Duplicates shown/hidden" toggle in the Alerts filter row.
  Repeat sightings within 25 m of an open alert are stored as
  status Duplicate (merged into that alert) and the list hides
  them by default - the toggle passes include_duplicates=true so
  they become visible, each row marked "merged into ALR-xxxx".
- No backend change needed (the API already supported it).

Everything else is identical to the 2026-11-02 build (evidence
media in the alert drawer, blob media loading, 10 s drawer poll).
